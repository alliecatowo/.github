# .github

Default community health files for [alliecatowo](https://github.com/alliecatowo) repositories.

GitHub applies these to any repo that does not have its own copy:

- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`
- Issue forms and config in `.github/ISSUE_TEMPLATE/`
- `.github/pull_request_template.md`

A repo can override any file by adding its own. The same files are included in [repo-template](https://github.com/alliecatowo/repo-template) for new projects.

The profile README lives in [alliecatowo/alliecatowo](https://github.com/alliecatowo/alliecatowo).
